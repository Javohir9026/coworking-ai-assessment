# Coworking Reservation Frontend

Nuxt 3, Vue 3, TypeScript strict mode va Pinia asosidagi frontend skeleti.

## Commands

- `npm run dev` — development server
- `npm run typecheck` — TypeScript tekshiruvi
- `npm run lint` — ESLint tekshiruvi
- `npm run format:check` — Prettier tekshiruvi
- `npm run test:e2e` — Playwright E2E testlari (testlar keyingi bosqichda)

`zod` forma/API ma'lumotlarini runtime validatsiya qilish uchun, `chart.js` esa admin dashboardidagi ikki chart uchun tanlangan. API hali mavjud emas; barcha services faqat typed contract/skelet hisoblanadi.
