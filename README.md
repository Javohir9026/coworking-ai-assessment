# Coworking Reservation Frontend

Nuxt 3, Vue 3, TypeScript strict mode va Pinia asosidagi coworking frontend.

## Commands

- `npm run dev` — development server (`http://localhost:3001`)
- `npm run typecheck` — TypeScript tekshiruvi
- `npm run lint` — ESLint tekshiruvi
- `npm run format:check` — Prettier tekshiruvi
- `npm run test:e2e` — Playwright member-login smoke testi

Frontend `http://localhost:3001` da, Nest API esa `http://localhost:3000/api` da ishlaydi. API ishlamasa UI xatoni ochiq ko‘rsatadi; local mock fallback yo‘q.
